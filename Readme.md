# PromLogix — Автономная логистическая платформа «ТОРК»

Программно-аппаратный комплекс автономного мобильного робота (AMR) для автоматизированной внутризаводской логистики, транспортировки деталей, документов и инструментов.

---

## Архитектура системы

Комплекс построен по 4-уровневой иерархической схеме:

```
[ Web-интерфейс & СУБД ]
           ▲
           │ REST API / WebSocket
           ▼
     [ Edge-сервер ]  (Маршрутизация парка, синхронизация при обрывах связи)
           ▲
           │ Wi-Fi / LAN
           ▼
  [ Робот: NVIDIA Jetson Nano ]  (Нейросетевое зрение DeepStream + YOLOv8)
           ▲
           │ UART / Serial
           ▼
  [ Контроллер: Arduino Mega ]  (Управление двигателями, датчиками, E-Stop)

```

1. **Web-интерфейс и БД**: Оформление заявок на перевозку, мониторинг перемещения в реальном времени, администрирование прав доступа по RFID и карт зон.


2. **Edge-сервер**: Координация флота роботов, балансировка задач, расчет маршрутов и локальное кэширование при сбоях внешней сети.


3. **Бортовой вычислитель (NVIDIA Jetson Nano)**: Высокоуровневая логика движения по узловому маршруту, инференс машинного зрения через аппаратный конвейер и отправка команд нижнему уровню.


4. **Контроллер нижнего уровня (Arduino Mega)**: Непосредственное управление приводами, опрос телеметрии и обеспечение аппаратной безопасности (экстренная остановка при сбоях верхнего уровня или препятствиях).

## Спецификация оборудования

* **Вычислители**: NVIDIA Jetson Nano и Arduino Mega — верхнеуровневый анализ видео/навигация и низкоуровневая автоматика.


* **Привод и шасси**: 4 двигателя суммарной мощностью 1 кВт, независимая подвеска — полный привод (4WD).


* **Рулевой механизм**: 2 сервопривода MG 996R с металлическими тягами — полноуправляемое шасси с рулением передней и задней осями.


* **Драйверы моторов**: JYQD-V7.3E2 — управление тяговыми двигателями.


* **Сенсорика препятствий**: LiDAR TOF200C / VL53L0X на поворотном механизме с сервоприводом SG90, УЗ-дальномер HC-SR04, боковой ИК-дальномер Sharp GP2Y0A41 — сканирование сектора движения, обход препятствий и стабилизация прямолинейного хода.


* **Компьютерное зрение**: USB-камера 1.3 Мп (1280x1024) — детекция дорожных знаков и светофоров.


* **Безопасность груза**: RFID-сканер RC522, электромагнитный замок, УЗ-датчик в крыше — авторизация доступа к отсеку и контроль наличия негабаритного груза.


* **Питание**: Основная АКБ 36В 4400 мА·ч, понижающий DC-DC преобразователь (36В $\rightarrow$ 5В) — раздельное питание силовой части и бортовой логики.
---

## Программный стек и машинное зрение

* **Конвейер видеоаналитики**: NVIDIA DeepStream SDK с обработкой в памяти видеопамяти GPU (NVMM) без лишних копирований в ОЗУ CPU.


* **Распознавание дорожных знаков**: Легковесная модель семейства YOLOv8 (v8n / v8s).


* **Детекция светофоров**: Гибридный метод — нейросетевая локализация корпуса светофора + алгоритмическая сегментация активного цветового сигнала через цветовые маски (HSV).


* **Протоколы связи**: Внутриузловой протокол UART между Jetson и Arduino, сетевое взаимодействие с Edge через WebSocket/HTTP API.
